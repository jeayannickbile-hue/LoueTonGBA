# LoueTonGBA 🚗

Application mobile pour louer des voitures à Abidjan, facilement et rapidement.

## 📱 Présentation

LoueTonGBA permet à tous les habitants d'Abidjan de louer une voiture en quelques clics, sans se déplacer.

## ✨ Fonctionnalités

- Voir les voitures disponibles
- Voir les détails d'une voiture (prix, places, photo)
- Réserver une voiture
- Voir ses réservations

## 🎨 Maquettes (Wireframe)

1. **Page d'accueil** - Accueil avec les voitures populaires
2. **Liste des voitures** - Toutes les voitures disponibles
3. **Réservation** - Formulaire pour réserver

## 🎨 Design

- Couleur principale : Jaune
- Couleur secondaire : Noir
- Style : Simple et moderne

## 🛠️ Technologies

- **Front :** Figma pour les maquettes
- **Back :** À venir (Gestion des voitures, réservations, utilisateurs)
